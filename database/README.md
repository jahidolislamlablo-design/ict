# ICT Easy Learning - ডেটাবেজ ও REST API সেটআপ গাইড

এই ফোল্ডারে আপনার **ICT Easy Learning** প্ল্যাটফর্মের জন্য একটি পূর্ণাঙ্গ, স্কেলেবল ও প্রফেশনাল ডেটাবেজ আর্কিটেকচার তৈরি করে দেওয়া হয়েছে।

---

## ১. কোন প্ল্যাটফর্ম ব্যবহার করবেন এবং কেন?

আমরা এই প্রজেক্টের জন্য বিশ্বখ্যাত ক্লাউড ডেটাবেজ প্ল্যাটফর্ম **Supabase (PostgreSQL)** নির্বাচন করেছি। 

### কেন Supabase সেরা?
1. **১০০% ফ্রি টিয়ার (Free Tier):** কোনো ক্রেডিট কার্ড ছাড়াই আজীবন ফ্রিতে ব্যবহার করা যায় (500 MB ডেটাবেজ স্টোরেজ, ৫০,০০০ মাসিক সক্রিয় ইউজার, ১ GB ফাইল/পিডিএফ স্টোরেজ)।
2. **অটোমেটিক REST API:** আপনার টেবিল তৈরি হওয়ামাত্রই সুপাবেস স্বয়ংক্রিয়ভাবে একটি দ্রুতগতির REST API (`https://your-project.supabase.co/rest/v1/...`) তৈরি করে দেয়। এর জন্য আলাদা কোনো Node.js বা Python ব্যাকএন্ড সার্ভার কোড লেখার বা হোস্টিং করার প্রয়োজন নেই!
3. **এক্সেলে (Excel) মতো ইউজার ফ্রেন্ডলি ড্যাশবোর্ড:** আপনি বা অন্য কোনো শিক্ষক সরাসরি ব্রাউজারে টেবিল এডিটর থেকে নতুন MCQ, সৃজনশীল প্রশ্ন, সাল বা বোর্ড সহজেই ইনপুট দিতে পারবেন। এছাড়া CSV ফাইল থেকে হাজার হাজার প্রশ্ন এক ক্লিকে ইমপোর্ট করতে পারবেন।
4. **পিডিএফ সাজেশন স্টোরেজ:** শিক্ষার্থীদের জন্য হ্যান্ডনোট ও সাজেশন পিডিএফ হোস্ট করার জন্য রয়েছে ফ্রি স্টোরেজ বাকেট।

## ২. ডেটাবেজ রেডি করার ৩টি সহজ ধাপ

### ধাপ ১: Supabase-এ ফ্রি প্রজেক্ট তৈরি করুন
1. ব্রাউজারে [https://supabase.com](https://supabase.com) ওয়েবসাইটে যান এবং **Start your project** এ ক্লিক করে একটি ফ্রি অ্যাকাউন্ট খুলুন (Google/GitHub দিয়ে সহজেই খোলা যায়)।
2. **New Project** এ ক্লিক করুন:
   - **Name:** `ict-easy-learning`
   - **Database Password:** একটি শক্তিশালী পাসওয়ার্ড দিন এবং লিখে রাখুন।
   - **Region:** `Singapore` (বাংলাদেশ থেকে সবচেয়ে দ্রুত গতির জন্য সিঙ্গাপুর রিজিয়ন নির্বাচন করুন)।
   - **Pricing Plan:** `Free Plan` সিলেক্ট করে **Create new project** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে ডেটাবেজ তৈরি হয়ে যাবে।

---

### ধাপ ২: টেবিল ও ডামি ডেটা তৈরি করুন (SQL Editor)
1. Supabase ড্যাশবোর্ডের বাম পাশের মেনু থেকে **SQL Editor** এ ক্লিক করুন।
2. **+ New query** তে ক্লিক করুন।
3. আপনার প্রোজেক্টের [`database/schema.sql`](schema.sql) ফাইলের সমস্ত কোড কপি করে এখানে পেস্ট করুন এবং নিচে ডানপাশে **Run** বাটনে ক্লিক করুন। 
   *(এর ফলে সব টেবিল, রিলেশন ও সিকিউরিটি পলিসি স্বয়ংক্রিয় তৈরি হয়ে যাবে)*
4. এরপর একইভাবে [`database/seed_data.sql`](seed_data.sql) ফাইলের কোডগুলো পেস্ট করে **Run** করুন। 
   *(এর ফলে বিগত সালের বোর্ড প্রশ্ন, অধ্যায়, মডেল টেস্ট ও সাজেশন ডাটাবেজে লোড হয়ে যাবে)*

---

### ধাপ ৩: ওয়েবসাইটের সাথে ডেটাবেজ কানেক্ট করা
1. Supabase ড্যাশবোর্ডের বাম পাশের নিচের দিকে **Project Settings** (গিয়ার আইকন) -> **API** অপশনে যান।
2. সেখান থেকে নিচের দুটি তথ্য কপি করুন:
   - **Project URL:** যেমন `https://xyzcompany.supabase.co`
   - **Project API Keys (anon / public):** লম্বা একটি কি (Key) পাবেন।
3. আপনার প্রোজেক্টের [`assets/js/api.js`](../assets/js/api.js) ফাইলে যান এবং উপরের `CONFIG` অংশে মানগুলো বসিয়ে দিন:

```javascript
const CONFIG = {
    USE_MOCK_API: false, // লাইভ ডেটাবেজ চালু করতে false করুন
    SUPABASE_URL: 'https://আপনার-প্রজেক্ট-আইডি.supabase.co',
    SUPABASE_ANON_KEY: 'আপনার-পাবলিক-এনন-কি-এখানে-বসাবেন'
};
```

ব্যাস! এখন আপনার ওয়েবসাইটটি সম্পূর্ণ অটোমেটিক ও ডাইনামিক ডেটাবেজের সাথে যুক্ত হয়ে লাইভ প্রশ্ন নিয়ে আসবে।

## ৩. ডেটাবেজ টেবিল পরিচিতি

| টেবিলের নাম | বিবরণ |
| :--- | :--- |
| `chapters` | আইসিটির সকল অধ্যায় ও টপিক লিস্ট |
| `boards` | ঢাকা, রাজশাহী, চট্টগ্রাম সহ ১০টি শিক্ষা বোর্ড |
| `colleges` | নটর ডেম, ভিকারুননিসা সহ শীর্ষ কলেজসমূহ |
| `mcq_questions` | সকল অধ্যায়, বোর্ড ও টেস্ট পেপারের বহুনির্বাচনি প্রশ্ন, অপশন ও ব্যাখ্যা |
| `cq_questions` | সৃজনশীল প্রশ্ন, উদ্দীপক, (ক, খ, গ, ঘ) অংশের আদর্শ সমাধান |
| `model_tests` | চূড়ান্ত মডেল টেস্ট ও স্পিড কুইজ তালিকা |
| `pdf_suggestions` | হ্যান্ডনোট, শিট ও সুপার সাজেশনের ডাউনলোড ফাইল ও লিংক |
| `user_profiles` | শিক্ষার্থীদের প্রোফাইল, কলেজের নাম ও প্রগ্রেস |
| `exam_results` | মডেল টেস্টের প্রাপ্ত স্কোর, সঠিক ও ভুল উত্তরের ইতিহাস |

---

## ৪. কীভাবে নতুন প্রশ্ন যুক্ত করবেন?
- Supabase-এর বাম মেনু থেকে **Table Editor** এ ক্লিক করুন।
- `mcq_questions` টেবিলে ক্লিক করে **Insert row** চাপুন এবং সরাসরি টাইপ করে প্রশ্ন, ৪টি অপশন এবং সঠিক উত্তরের ইনডেক্স দিয়ে **Save** করুন।
- কোনো কোড ছাড়াই ওয়েবসাইটে সেই প্রশ্নটি স্বয়ংক্রিয়ভাবে চলে আসবে!
